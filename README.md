# 🎓 AI Placement Prep Agent

An AI-powered placement preparation platform built using **IBM watsonx Orchestrate** that generates personalized roadmaps, identifies skill gaps, and prepares students for campus recruitment.

---

## 📌 Project Overview

Students preparing for campus placements often struggle with structured preparation—they find it difficult to identify core topic priorities, pinpoint missing technical skills, and locate relevant mock interview questions.

The **AI Placement Prep Agent** solves this by analyzing a student's profile, target job role, and timeline to deliver a tailored, actionable preparation roadmap.

---

## 🎯 Key Features

- **Personalized Roadmaps:** Custom study plans aligned with your target role and available prep time.
- **Skill Gap Analysis:** Highlights missing competencies and provides targeted learning recommendations.
- **Role-Specific Mock Prep:** Practice questions customized for specific tech stacks and job titles.
- **Interactive AI Assistant:** Powered by IBM watsonx Orchestrate for natural, conversational guidance.
- **Exportable Plans:** Download your complete preparation roadmap for offline reference.
